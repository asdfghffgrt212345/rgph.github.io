# Лабораторная работа 2
## Цель проекта
Цель проекта — организовать учебные материалы в понятной структуре, добавить описание проекта и сделать его воспроизводимым.
## Состав проекта
- `notebooks` — лабораторная работа №1 в формате Jupyter Notebook.
- `data` — учебные данные, используемые в проекте.
- `docs` — документация и журнал версий проекта.
- `README.md` — описание проекта и инструкция по проверке.
## Как открыть
Репозиторий открывается через GitHub в браузере. Файл лабораторной работы находится в папке `notebooks` и может быть открыт через Google Colab.
## Как проверить
Нужно открыть notebook из папки `notebooks` и выполнить его ячейки. Также необходимо проверить наличие папок `notebooks`, `data` и `docs` и убедиться, что файлы находятся в соответствующих папках.
## Ограничения
В проекте не используются персональные данные, пароли, токены и другие конфиденциальные сведения.
## История версий
История изменений проекта записывается в файле `docs/version_log.md`.
## Как проверить воспроизводимость
Нужно открыть notebook и выполнить все ячейки по порядку.
После выполнения проверить, что код работает без ошибок и результаты появляются.
Также нужно убедиться, что необходимые файлы находятся в папке `data`.
